さくらインターネット株式会社の高火力 DOKで超解像（Super Resolution）処理を行うためのコード群です。

# 処理概要
1. オブジェクトストレージに超解像元画像を格納
2. settings.csvに対象ファイルパスと出力倍率、出力ファイル名接尾辞を記入
3. callSuperResDOK.ps1の第一引数にsettings.csvのファイルパスを設定し、実行（高火力 DOKのAPIを呼び出し、タスク生成）
4. 高火力DOKが超解像を行い、出力先バケットに超解像後ファイルを出力

# 動作準備
1. filesForDocker内のファイルを用いて、docker build/login/pushをし、コンテナレジストリにDockerイメージを格納します。
2. コンテナレジストリのユーザー情報を、高火力 DOKのレジストリー認証情報に登録、IDを控えます。
3. さくらのクラウドホームで高火力 DOK作成権限を有する認証情報、オブジェクトストレージで入出力に用いる認証情報を取得します。
4. 上記値をcallSuperResDOK.ps1に貼り付けます。イメージ名はbuild時の設定に準じます。

# 注意事項
## ファイルの親ディレクトリについて
csvのファイルパスにはファイルの親ディレクトリも含めることができます。ただし、ルートの「/」は記載しないでください。
- 良い例：workdir/abc.jpg
- 悪い例：/workdir/abc.jpg

親ディレクトリを含めた場合は、出力先バケットにも同じ階層の親ディレクトリを作成し格納します。

## 出力先バケットについて
入力バケットと出力バケットは、同じにすることも、分けることもできます。
同じに設定し、かつ接尾辞を設定しなかった場合、元画像が上書きされます。バージョニング機能を有効にしていない場合、元画像を取得できなくなってしまいますので、注意してください。
